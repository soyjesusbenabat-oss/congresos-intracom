# congresos.portalintracom.com

Web de Intracom como secretaría técnica de congresos académicos.

Es un sitio estático publicado con GitHub Pages: `index.html` en la raíz, con `styles.css`,
`tipografia.css`, `app.js` (interacción) y `data.js` (contenidos: servicios, congresos, precios y
preguntas frecuentes). Las imágenes están en `assets/` y `uploads/`.

Para cambiar textos o congresos del portafolio, se edita `data.js`. Cada cambio que se sube a `main`
se publica solo.
